ENGLISH IN 30 DAYS
Academic English for Arabic speakers, levels A2 to B1.

A free, static website: plain HTML, CSS and JavaScript. No build step, no server, no account, no tracking,
no external scripts, fonts or analytics. Progress is saved only in the learner's own browser (localStorage).
Audio uses the browser's built-in speech synthesis. Speech recognition is optional and off by default.

HOW TO TRY IT ON YOUR COMPUTER
Open index.html in a browser (double-click it). Everything works from a file path too.

HOW TO PUBLISH ON GITHUB PAGES (only when you decide to)
1. Create a new public repository on GitHub (for example "english-30").
2. Upload everything in this folder (the .gitignore already leaves out the development files).
3. In the repository: Settings, Pages, Source "Deploy from a branch", branch "main", folder "/ (root)", Save.
4. After a minute the site is live at https://YOUR-USER-NAME.github.io/REPOSITORY-NAME/

WHAT IS IN THE FOLDER
index.html          course map (30 days, 6 units)
lesson.html         the lesson page (lesson.html?d=1 ... 30)
review.html         spaced-repetition cards
practice.html       extra dictation and speaking practice
pronunciation.html  sounds that are hard for Arabic speakers
glossary.html       every word from the lessons
writing.html        all writing tasks and drafts, AI-tutor prompts
summary.html        printable unit summaries (summary.html?u=1 ... 6)
certificate.html    unlocked after passing the Day 30 test (70%)
settings.html       Arabic on/off, theme, text size, voice, backup
assets/             CSS and fonts (local only)
js/                 the engine and the 30 day files (js/days/dayNN.js)

BACKUP
Learners can export and import their progress in Settings. Progress lives only in one browser on one device.

CONTENT
All texts, dialogues and exercises are original to this course.
